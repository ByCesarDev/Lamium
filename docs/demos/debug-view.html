Debug View を独立要素にする（A 案に決定）

Java の F3 は「左にプレイヤーと世界の情報、右に Java・CPU・GPU・メモリ」の2分割です。Bedrock の右列に何を置けるか調査したところ、クライアント設定（描画距離・レイトレーシング・Vibrant Visuals・雲・最大 FPS・フルスクリーン）は SDK だけで、PC 情報（メモリ・CPU・GPU・表示・OS）は Windows API で取得できる見込みでした。右列が埋まるため A 案（照準は左下・Java 準拠）を採用し、B は実装しません。B と C のタブは比較の記録として残しています。どの案でも Debug View は Info HUD・Target とは別の HUD 要素で、オンにしても通常の HUD 設定は変わりません。F3 で切り替え、配置・大きさ・背景・影は配置エディタで編集できます。値はサンプルで、実体数・チャンク数・粒子数は L-57（調査）待ちです。

    共通: 既定はオフ / F3 で切替 / 影あり・背景なしが初期値（背景は要素設定で変更可）/ Info HUD と Target は独立して表示。
    点線 = L-57 の調査後に追加する候補 / 青線 = Windows API で取得（取れない環境では行ごと非表示）。

    案左列右列特徴
    Aバージョン・性能・位置・世界・照準（Java 準拠）クライアント設定＋PC 情報（右寄せ）Java の配分そのもの。右列も埋まる。照準は左下
    Bバージョン・性能・位置・世界照準対象（上・3行固定）＋クライアント設定＋PC 情報（右寄せ）照準が右端。Java は照準も左なので配置は Java 準拠ではない。システム行は下で固定
    Cすべて1列（照準・システムも含む）なし右端を見なくて済む。全部入りで20行前後と縦長
