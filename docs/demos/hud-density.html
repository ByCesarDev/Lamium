HUD の行間と行ごとの背景

Info HUD（左上）と Status（右中央、マーカー付き）を GUI 倍率 2 の画面で表示しています。1 GUI 単位 = 2 px。今の Lamium は行の高さ 14、背景は「なし」か「カード」の 2 択です。行の高さ、背景、行ごとの背景の余白とすき間、言語を切り替えて比べてください。文字は Minecraft のフォントではなく近い等幅フォントの代用です。

確認したいこと（2026-10-06 決定: Info・Status・Debug View 共通の「HUD の行の高さ」9〜16、既定 14 はゲームで比べて決める。背景に「行ごと」を追加（余白 1・くっつける固定）、Debug View にも背景。右寄せなし）

  1. 対象：Info HUD と Status（共通の描画を使う要素）から始めるか。耐久値 HUD・ターゲットカード・Schematic HUD はアイコンやバーで行の高さが決まっているので、後回し（または対象外）を推奨。
  2. 行間の設定の形：行の高さを数値で選ぶ（例 10〜16、1 刻み）か、「標準 / 詰める」のようなプリセットか。要素ごとの設定（HUD の各要素の行に追加）か、全要素共通か。
  3. 既定値：今と同じ 14 のままにするか、詰めた値（例 12）にするか。日本語の文字は英語より背が高いので、日本語で詰めすぎないかも見てください。
  4. 行ごとの背景：横の余白、行どうしをくっつけるか 1 単位あけるか。
