決定事項（2026-10-02、★ の案）

論点決定理由・補足
1. 位置左に固定Bedrock には利き手の設定がないので「利き手の反対側」に追従させる元がない。Java の既定（右利き → 左側）と同じ。右も選べる設定は、要望が出てからでよい。
2. 枠ホットバーと同じ見た目バニラの HUD の一部に見える。カードは Lamium の HUD 要素と揃うが、ホットバーの隣では浮いて見える。
3. 個数・耐久値バーホットバーと同じく出す矢・ロケット花火の残数と盾の耐久がわかる。ゲームのアイテム描画がそのまま描く想定（実装前に調べる）。
4. 空のとき隠す（設定で空枠も選べる）何も持っていないときは画面を増やさない。空枠は「オフハンドが空だ」と気づきたい人向けのオプション。
5. 配置エディタで動かせるか動かさない（ホットバーに付いて動く）ホットバーの横であることに意味がある。UI スケールやクラシック／ポケットの違いはホットバーの位置から追従する（実装前に調べる）。
6. 設定の置き場所案 1：「HUD・オーバーレイ」の独立した行耐久値 HUD のオフハンド表示とは別物として並ぶ。両方オンだと盾の耐久が 2 か所に出るが、害はない。
7. 既定値既定オフバニラの HUD に足す表示なので既定オフが無難。トーテムが見えるのは誰にとっても便利なので既定オンもありうる。
