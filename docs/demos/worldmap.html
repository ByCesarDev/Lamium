ワールドマップ：開いた画面、操作、ウェイポイント、設定の行

step 0 で決まったこと：全画面＋細い上下バー、右クリックメニューでウェイポイントを操作、ワールドマップが有効ならミニマップの表示に関係なく記録、保存した地図は上限なし＋設定から削除。下の画面は実際にドラッグで移動・ホイールで拡大縮小・右クリックでメニューが使えます。地形は生成したもので本物ではありません。

保存済みの領域が近い順にすぐ出て、そのあと周囲の新しいチャンクが記録されて埋まっていく様子です。

設定画面「マップ」に加える行

ウェイポイントの下に「ワールドマップ」を足します。地図の中で変えられるもの（ネザーの層を自分の高さに合わせるか、など）もここに同じ設定として並びます。

マップ
▾ ワールドマップ 2試験的M
ネザーの層を自分の高さに合わせる
保存した地図（このワールド）　18.6 MB消す

親の行：スイッチは記録と画面の ON/OFF（オフにすると記録も止まる）、キーは「ワールドマップを開く」。「消す」は 2 回押しで、このワールド（サーバーはアドレスとポートごと）の全ディメンションの地図を消します。表示の設定（プレイヤー・ウェイポイント・死亡地点）はミニマップと同じものを使い、ワールドマップ用は作りません。

開く・閉じる・操作

  • キー（既定 M）で全画面に開く。同じキーか Esc で閉じ、カーソルの捕捉と視点操作を必ず戻す
  • ゲームは止めない（シングルでも）。HUD とミニマップは開いている間は出さない
  • 左ドラッグで移動、ホイールでカーソル位置を中心に拡大縮小（1 ブロック = 1/8〜16 px）
  • Space か「自分に戻る」で自分を中央に。開いたときは毎回自分が中央・前回の拡大率
  • 北が上で固定（回転しない）

記録と保存

  • ワールドマップが有効なら、ミニマップを隠していても周囲を記録（1 フレームの処理量に上限）
  • 256×256 ブロックごとのファイルに色と高さを保存。ローカルはワールドの lamium フォルダ、サーバーは Lamium の config にアドレスとポートごと
  • 開くと保存済みの領域が近い順にすぐ出る。読み込み・描画は別スレッドで、ゲームを止めない
  • ミニマップも同じ保存データを読むので、来たことのある場所はミニマップでもすぐ出る
  • ネザーは 16 ブロックごとの層で記録。オーバーワールドの洞窟は v1 では記録しない

ウェイポイント

  • 右クリック（何もない場所）：「ここに追加」→ いつもの追加の入力。Y は記録済みの地表の高さ（未記録なら自分の高さ）
  • 右クリック（印の上）：「編集」でウェイポイントの画面のその行を開く、「隠す / 表示する」、「削除」（2 回押し）
  • 死亡地点：「ウェイポイントにする」「削除」
  • 隠したウェイポイントも地図上では薄く出す（右クリックで戻せるように）
  • テレポートはしない

確認したいこと

  1. 上下のバー：上＝ディメンションの切替（自分のいる所に ●、記録のない所は灰色）・ネザーの層・自分に戻る・ウェイポイント画面・閉じる、下＝カーソルの座標と高さとバイオーム・操作のヒント・縮尺、でよいか。
  2. ほかのディメンションを見る：オーバーワールドにいながらネザーの地図を見られる切替を付けるか（付けない場合は今いるディメンションだけ）。
  3. ネザーの層：16 ブロック刻み、既定は自分の高さに合わせ、◀ ▶ で手動に切り替わる、でよいか。
  4. ウェイポイントの名前：地図上で常に出す（このモック）か、カーソルを重ねたときだけにするか。
  5. 右クリックメニュー：上の項目でよいか。「ここを中央に」なども要るか。
  6. 設定の行：上の 3 行（機能の行と開くキー、ネザーの層、保存した地図の容量と「消す」）でよいか。消すのはワールド単位（全ディメンション）でよいか。
